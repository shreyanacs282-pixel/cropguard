`server/src/data/library.js`:

Until a file exists the card shows a leaf or insect icon instead, so the
app looks finished with no images at all.

Good free sources: your own field photos, the PlantVillage dataset, and
ICAR or state agriculture department publications (check the licence).
Around 800x600 is plenty.
